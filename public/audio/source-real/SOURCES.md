# Real Sound Sources

These source files are used to render the `Sound Experience` MP3 variants.

- `applause.ogg` - Wikimedia Commons, "Sound Effects - Applause after a concert.ogg", CC0 1.0, author Amada44.
- `laughter.ogg` - Wikimedia Commons, "Laughter.ogg", public domain, author ezwa / PDSounds.

Planned real-source slots:

- `fireworks.mp3` - real fireworks/booms.
- `cash-register.mp3` - real cash register/casino reward accent.
- `windchimes.mp3` - real chimes for magical/floral/star effects.
- `howling-wind.mp3` - real wind ambience for snow/neon/atmosphere.
- `bell.wav` - real bell for Christmas/birthday/reward accents.

Wikimedia temporarily returned HTTP 429 while downloading the remaining files, so the generator falls back to synthetic layers only when a real source is unavailable.
